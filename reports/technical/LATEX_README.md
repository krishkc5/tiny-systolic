# TinySystolic LaTeX report

Upload all contents of this ZIP to Overleaf and select TinySystolic_Technical_Report.tex as the main document. Use XeLaTeX (or a standard LaTeX distribution with the listed packages). Preserve the figures/ and evidence/ directory structure.

All report narrative, tables and 11 figures are included. The built-in Codex standalone compiler successfully compiled the source, but cannot load companion image files: its preview uses explicitly labelled placeholders. A full image-bearing PDF has not been compiled or visually verified in this conversion. In a complete project, the source automatically loads the supplied images instead.

The original evidence cutoff and hardware revision remain unchanged. No RTL changes were made.
