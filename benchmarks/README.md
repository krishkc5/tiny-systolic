# Benchmark contract

No accelerator benchmark results exist yet. Record compute cycles and complete host-to-result cycles separately. Compare the eventual four-PE array against a one-MAC baseline at K=1,2,4,8,16 using identical signed arithmetic, interfaces, and timing assumptions. The standalone MAC is available, but an equivalent scheduled sequential baseline remains to be implemented. The full-chip tests measure and assert 2K+11 no-stall transaction cycles; these are simulation cycles, not measured silicon throughput. See ../docs/architecture.md for metric definitions. Keep simulated, post-route, and silicon measurements separate.
